# Nocturne Creator Studio

Run the local site with `npm install` and `npm run dev`, then open the Vite URL with `?creator=1` (usually http://localhost:5173/?creator=1). Creator Mode is available only in development. The public site does not show the editor or load local browser edits.

The Creator panel changes the real 3D scene live. Open the Spheres section to select and drag spheres, or edit their depth, size and rotation. The bottle can be dragged for rotational momentum. Particle forces run in the existing GPU simulation. Preview hides the panel.

Edits are saved automatically in this browser. Save Scene saves explicitly; presets, undo/redo, JSON import, and Copy/Export are in the panel. **Set as Default / Download JSON** downloads the current complete configuration. To publish an approved composition, replace `Public/Assets/Config/creator-studio.default.json` with that exported file, commit it, then deploy through the usual review process. Browser storage alone never updates the public site. Compatible saved values take priority over new defaults in Creator Mode. On first open, the editor also migrates compatible bottle, camera and key-light values from the previous scene editor. Its original browser data remains intact; the new garden uses different sphere and particle structures, so those old layouts cannot be mapped safely.

The expanded studio supports adding, duplicating and deleting spheres, per-sphere glass/rose/amber/cream/gold/moss materials, and GPU particle density and sphere drag forces. Particle density rebuilds the garden and retains saved sphere transforms. The small green moss pieces and bright particles share one GPU simulation, reacting to cursor proximity at any scene depth. Open Particles to adjust Cursor repulsion, Cursor attraction, Cursor radius, Velocity sensitivity, Return strength and Particle damping; Green particle response adjusts the moss layer separately. Movement keeps momentum and settles back toward its original position. Fog uses the sky shader. Hue, saturation, brightness, warmth and glow brushes are localized film-pass color grading; they do not paint physical lights. The 64 most recent strokes are rendered by the film shader and saved in JSON. Preview hides editing controls and brush outlines.

Current limitations: this is an iterative core editor, not a complete Blender-style tool. Particle distribution, clustering, depth and turbulence remain procedural; sphere physics, 3D light handles, shadow controls, material reflection sliders, vertical bottle drag, brush softness/opacity, responsive viewport previews and separate mobile compositions are not implemented. The bottle geometry cannot be reshaped here. Local save and presets do not update GitHub Pages. Browser verification requires a WebGL-capable development browser; a build alone cannot prove the scene renders on every GPU.
