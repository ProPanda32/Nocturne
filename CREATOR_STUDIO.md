# Nocturne Creator Studio

Run the local site with `npm install` and `npm run dev`, then open the Vite URL with `?creator=1` (usually http://localhost:5173/?creator=1). Creator Mode is available only in development. The public site does not show the editor or load local browser edits.

The Creator panel changes the real 3D scene live. Open the Spheres section to select and drag spheres. The on-scene handle resizes the selected sphere; the panel also edits its depth, material and rotation. The bottle responds to horizontal and vertical drags and retains angular momentum. Particle forces run in the existing GPU simulation. Preview hides the panel.

Edits are saved automatically in this browser. Save Scene saves explicitly; presets, undo/redo, JSON import, and Copy/Export are in the panel. **Set as Default / Download JSON** downloads the current complete configuration. To publish an approved composition, replace `Public/Assets/Config/creator-studio.default.json` with that exported file, commit it, then deploy through the usual review process. Browser storage alone never updates the public site. Compatible saved values take priority over new defaults in Creator Mode. On first open, the editor also migrates compatible bottle, camera and key-light values from the previous scene editor. Its original browser data remains intact; the new garden uses different sphere and particle structures, so those old layouts cannot be mapped safely.

The studio supports adding, duplicating and deleting spheres, per-sphere glass/rose/amber/cream/gold/moss materials, and GPU particle density and sphere drag forces. Particle density, palette, spread, depth and clustering rebuild the garden and retain saved sphere transforms. The small green moss pieces and bright particles share one GPU simulation, reacting to cursor proximity at any scene depth. Open Particles to adjust cursor force, radius, speed sensitivity, momentum, damping, turbulence, return strength and color. Green particle response adjusts the moss layer separately. Movement keeps momentum and settles back toward its original position. Sphere drag interaction and damping control the nearby particle wake.

Bottle glass, liquid, crystal and gold controls change the existing GLB materials. Key, rim, back and warm light settings affect real Three.js lights. Exposure and reflections affect rendering; bloom, highlight, shadow, temperature and atmosphere grading are screen-space presentation effects. Fog and backdrop tint use the sky shader. Hue, saturation, brightness, warmth and glow brushes are localized film-pass color grading; they do not paint physical lights. Drag a brush across the scene to paint. Brush softness and opacity affect the mask. The 64 most recent strokes are rendered by the film shader and saved in JSON. Camera controls include position, rotation, zoom, field of view and separate mobile framing and bottle scale. Use the Camera section's viewport selector to preview common screen sizes. Preview hides editing controls and brush outlines.

Current limitations: this is a practical real-time editor, not a complete Blender-style tool. Particle distribution and turbulence remain procedural. Sphere rotations use a single Y axis; sphere floating is animated and drag directly changes its saved position, without rigid-body collisions. Light placement uses numeric controls instead of 3D handles. Shadows and localized brushes are screen-space effects, not physically painted lights. Responsive settings include a separate mobile bottle scale and framing, but not independent per-device sphere layouts. The GLB bottle geometry cannot be reshaped here. Local save and presets do not update GitHub Pages. Browser verification requires a WebGL-capable development browser; a build alone cannot prove the scene renders on every GPU.
